# SmartMenuOptim.Shared Project Resume

## Overview
This project contains shared code and resources used across the SmartMenuOptim solution. It targets .NET 9 and is designed to provide common models, utilities, and logic for other projects, promoting code reuse and consistency.

## Technologies & Frameworks
- .NET 9
- Microsoft.EntityFrameworkCore (data access and ORM)
- Newtonsoft.Json (JSON serialization)

## Key Features
- Shared data models and DTOs
- Common utilities and helper classes
- Centralized logic for use by API, Server, and other components

## Getting Started
1. Open the solution in Visual Studio 2022.
2. Restore NuGet packages.
3. Reference this project from other projects as needed.

## Structure
- Contains code intended for reuse across the solution
- No direct entry point; used as a class library
