# SmartMenuOptim.Tests Project Resume

## Overview
This project provides automated tests for the SmartMenuOptim solution, ensuring the reliability and correctness of both the API and Server components. It targets .NET 9 and leverages modern testing frameworks and tools.

## Technologies & Frameworks
- .NET 9
- xUnit (unit testing)
- Moq (mocking)
- FluentAssertions (assertions)
- Microsoft.AspNetCore.Mvc.Testing (integration testing)
- Coverlet (code coverage)

## Key Features
- Unit and integration tests for API and server logic
- Uses mocks and fluent assertions for clear, maintainable tests
- Collects and reports code coverage

## Project References
- SmartMenuOptim.API
- SmartMenuOptim.Server

## Getting Started
1. Open the solution in Visual Studio 2022.
2. Restore NuGet packages.
3. Build the solution.
4. Run tests using Test Explorer or with `dotnet test`.
